# Изучение Openldap


## Конфигурация для изучения

Docker образы:
- LDAP-сервер [`osixia/openldap:1.5.0`](https://hub.docker.com/r/osixia/openldap/)
- UI: [`osixia/phpldapadmin:0.9.0`](https://github.com/osixia/docker-phpLDAPadmin)
- Приложение с поддержкой LDAP-auth: [`grafana/grafana:13.0`](https://hub.docker.com/r/grafana/grafana)
